Web-based tool for analyzing the Electronic Code of Federal Regulations (eCFR).

The CFR is organized in a hierarchy of levels: Title, Subtitle (Rare), Chapter, Subchapter, Part, Subpart, Section. Sections correspond to specific regulations.

On a regular (weekly) basis, the tool downloads the up-to-date contents of the eCFR and contructs a local database from them.

HOW TO USE:

In the application, select the desired metric to use for analysis (e.g., lexical diversiy of sections). Then select the parameters of you're specific statistical query. A UI for entering metric-specific parameters appears once a metric is selected.

For example, if you choose the 'Lexical Diversity' metric, which measures how variable or repetative the word choice is within a level, you must select a title, and a level.
If you select title=2, level='Subchapter', the tool will display a table showing the lexical diversity scores, from 0 (repetative) to 1 (diverse) for each subchapter in title 2.
